# Esp32-Tetris
Simple Tetris playeable, using a LCD 0,96'' screen and two potenciometers for rotate and move de pieces.
The only you need to play this proyect is:
  -two potenciometer
  -one screen 0,96'' lcd (the code is made for this parameter)
  -Esp32 or any devboard like arduino
Just download the code (it have all the libraries that you need) and upload the code in your dev board and enjoy!!
